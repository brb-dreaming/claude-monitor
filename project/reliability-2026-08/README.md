# Agent Monitor Reliability Project — August 2026

This directory tracks the August 2026 reliability and readiness review.

## Objectives

- Establish the app's current correctness and operational risk profile.
- Make stability and failure behavior explicit and testable.
- Produce a prioritized roadmap suitable for a growing user base.
- Assess independent distribution and a possible Tugboat bundle.

## Working rules

- Existing uncommitted source changes are preserved as user work.
- Findings include evidence, impact, confidence, and a recommended fix.
- Remediation is implemented in priority order and verified before rollout.

## Files

- `first-impressions.md` — baseline orientation report.
- `review-plan.md` — review tracks and deliverables.
- `findings.md` — detailed findings.
- `roadmap.md` — prioritized remediation plan.
- `checks.md` — original review evidence and reproducible checks.
- `external-contracts.md` — Claude Code and Codex integration assumptions.
- `p0-baseline.md` — source and worktree state captured before remediation.
- `p0-implementation.md` — P0 changes, verification, and remaining boundaries.
